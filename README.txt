TEACHING JOURNAL PRO — TEACHERS EDITION

Shareable, customisable version for colleagues.
Teachers can change school, teacher and school-year details, and add/rename/remove classes. Renaming updates related journal sessions and timetable slots. Removing a class deletes its sessions and timetable slots after confirmation.

DATA AND PRIVACY
Journal data is stored in each browser and does not sync between teachers or devices. Do not upload student data or backups to the public GitHub repository. Use Backup data regularly; local snapshots are not a substitute for an external backup.

PUBLISH
Upload the contents of this folder directly to the root of a public GitHub repository. Then open Settings > Pages > Deploy from a branch > main > /(root) > Save. Share the resulting GitHub Pages address with colleagues. For app installation/offline caching, open the HTTPS site in Chrome and load it once while online.
